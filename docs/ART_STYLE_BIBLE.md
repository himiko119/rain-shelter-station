# Art Style Bible — 雨夜の絵本

## Core sentence

古い地方駅を舞台に、深い雨夜の中へ人の記憶だけが琥珀と珊瑚で残る、柔らかなデジタル絵本。

## Rendering style

- やや簡略化したアニメ調の形に、薄い筆致と材質の擦れを重ねる。
- 写真写実には寄せず、ゲームサイズで形が読める輪郭を優先する。
- 一つの画面に主光源を一つ置き、補助光は色温度の対比に使う。
- 同じ密度を全面へ敷かず、物語の焦点と歩行域を最も明快にする。
- 特定作品、作家、スタジオ固有の描線や顔立ちは模倣しない。

## Line

- 背景は輪郭線より明度差と面で形を分ける。
- キャラクターと重要アイテムには暗い青紫の1–2px相当の輪郭を残す。
- 遠景の線は細く、低コントラストかつ青寄りにする。
- UIは1pxのhairlineを基本とし、二重枠と過剰な装飾を避ける。

## Shading and materials

- 基本は大きな陰影2段階 + 柔らかな反射光 + 局所的な質感。
- 木は不均一な擦れ、金属は細い縁光、紙は繊維感、濡れ面は方向性のある反射で区別する。
- 反射は実物の鏡像を強く描かず、主光源色を低いコントラストで引き延ばす。
- 黒で潰さず、最暗部にも青紫の色相差を残す。

## Background density

- 遠景: 20–35%のコントラスト。大きな形と光点のみ。
- 中景: 建築と主要設備。場所を識別できる密度。
- 歩行域: 低いテクスチャ密度と大きな明度面。足元を埋没させない。
- 前景: 画面端か接地物の一部だけ。全画面前景は禁止。
- 重要物: 周囲より一段明るい縁、色差または局所的な空白で示す。

## Character proportions

- ナギ: 高校生相当、頭身約5.5。ゲーム表示では全高72–88pxを基準にする。
- 駅員: 約6頭身、直線的で整った輪郭。
- 乗客: 4.8–6.2頭身の範囲で年齢、身長、肩幅、姿勢を変える。
- 手足を過度に細くせず、32–48px幅でもポーズが読める形にする。
- 全キャラクターの接地点はbottom-center。影は楕円を共通化するが大きさを体格へ合わせる。

## Nagi identity lock

- 近い黒の短いボブ。左側へ小さな琥珀の髪留め。
- 青緑を含む濃紺のレインコート、生成りの襟、珊瑚色のマフラー。
- 使い込んだ茶革の小型鞄、濃紺スカート、黒い靴下、茶のローファー。
- 暗い乗客より明るい輪郭と、雨青・琥珀の両リムライトを受ける。
- 幼児化、大きすぎる目、方向ごとの衣装変化を禁止する。

## Light sources

- 待合室: 上部の琥珀灯。窓から弱い雨青。
- 改札: 駅員窓口の琥珀 + 券売機の青白。
- 駅員室: 台帳を照らす机上灯。
- 跨線橋: 青白い蛍光灯 + 遠端の琥珀。
- ホーム: 屋根下の琥珀灯、信号の赤、段階に応じた列車・夜明け。
- 人物の縁光と接地影は、その場の主光源方向へ合わせる。

## Rain and wet surfaces

- 遠景雨は細く低速、中景雨は標準、前景雨は少数で速く太い。
- 屋内では窓面の流れを主とし、室内空間へ雨線を出さない。
- 水たまりは雨量より場所を示す。波紋は常時3層以上を強く動かさない。
- reduced motionでは雨量、波紋、マーカーの移動、長いフェードを縮減または停止する。

## UI

- 採用案は「Quiet Station Signage」。深紺の半透明面、1px枠、琥珀の細いアクセント。
- 背景を見せるため、通常HUDは場所、短い目的、近接調査、必要な3操作だけ。
- タイトルは駅名標、ノートは手帳、所持品は旅行鞄、記録は切符のモチーフを残す。
- 会話、設定、通知はモチーフを弱め、本文と操作を優先する。
- 角丸は4–12px。大きなカードでも16pxを越えない。
- フォーカスはrain-500の2px + 外側1pxのnight-950で常に見える。

## Memory scenes

- 探索背景より感情密度を一段高くする。
- 顔の正面描写だけに頼らず、手、背中、足元、小物、季節光で語る。
- 全6枚に共通の暗い青紫フレーム、珊瑚のbloom、生成りのcaption面を使う。
- 重要アイテムはゲーム内基準アセットと同じ形・傷・意匠を保つ。

## Dawn and endings

- 夜明けは全体を白くせず、最暗部をnight-800まで持ち上げ、空へdawn-blueとdawn-pinkを加える。
- Ending A: 青い終電を斜めに横切らせ、冷たさと残置感を強調。
- Ending B: 雨上がりの広い空と始発、淡い逆光。最も明るく開放的。
- Ending C: 駅員室またはホーム端のナギと一灯。暖かいが余白の多い孤独。
- 色替えだけでなく、カメラ位置、人物距離、光源を変える。

## Forbidden treatments

- 意味不明な生成文字、看板、数字、手指や建築の崩れ。
- 全面が同じ細密度、過度なフォトリアル、強いホラー、血や汚損。
- 主要人物・背景を単純な円、四角、CSS artだけで完成扱いにすること。
- 大量のglow、常時の強い揺れ、点滅、全画面前景、黒潰れ。
- ランタイムでスクリーンショットを引き伸ばすこと、巨大な未使用候補を同梱すること。

## Display standards

### 1280 × 720

- 世界表示を主面積の75%以上に保つ。
- 通常HUDの各面は画面幅30%未満、会話は高さ24%未満を目安にする。
- ポートレートは幅118–180pxで本文列と重ならない。

### 390 × 844

- world、目的、操作を縦に分離し、横スクロールを発生させない。
- 主要タッチ領域は44px以上。safe areaを維持する。
- 会話立ち絵は幅88–112px、高さ146px以下で本文を圧迫しない。
- 記憶画像は高さ260px以下、所持品は1列で画像を64px以上確保する。
