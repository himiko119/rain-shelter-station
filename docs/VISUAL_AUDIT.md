# ビジュアル監査 — visual overhaul v2

基準日: 2026-07-14

対象は公開済みコミット `21a9ae9`。1280×720、390×844の既存スクリーンショット、`StationView`、`ExplorationScene`、DOM UI、エリア定義を照合した。変更前の品質基準は `npm run check` 成功（Vitest 33件）とPlaywright 9/9成功である。

## 総評

現行版は、操作対象、HUD、会話、ノートの可読性と、5エリアをつなぐゲーム進行が安定している。一方、Canvas内の多くが塗りつぶし矩形、均等グリッド、円、文字記号で構成されているため、画面を静止画で見たときに「古い地方駅の具体的な場所」より「駅を示す模式図」に近く見える。今回の改修では、座標、衝突、hotspot、セーブ形式を変えず、同じ配置へ素材感、輪郭、接地、光、前後レイヤーを加える。

## エリア別の識別目標

- 待合室: 木と曇りガラス。停止時計と暖色灯が焦点。
- 改札口: 金属、白い案内面、床誘導線。中央の改札列が焦点。
- 駅員室: 狭い事務机、紙、琥珀色の卓上灯。台帳と鏡が焦点。
- 跨線橋: 青灰の金属、連続窓、消失点、錆。奥の階段が焦点。
- 雨のホーム: 屋根梁、黄色線、黒い線路、信号、水面。駅名標と夜明けが焦点。

## キャラクターと調査対象

ナギは淡い襟、青緑の上着、革色の鞄、明るい輪郭を固定し、乗客より高い色差を持たせる。乗客は身長、肩、頭部、姿勢、アクセサリーを個別化する。hotspotの常時マーカーは面積と明滅を弱め、対象物そのものの色、接地影、近接時の細いリングで誘導する。

## UIとコントラスト

本文の生成り色と濃紺面の高コントラストは維持する。角丸カードの反復を減らし、駅名標、切符、記録帳、金属窓枠の直線的な形へ寄せる。HUDは左右上端と目的チップだけに保ち、中央と主人公周辺を空ける。状態は色だけでなく、文字、印、輪郭で示す。

## モバイル監査

390×844ではCanvasが約390×219pxに縮小され、上下の余白へHUDとタッチUIを置く設計は安定している。一方、38pxの補助ボタンがあり44px基準を下回る。改修では全補助ボタンを44px以上とし、目的チップと操作表示の間隔を維持する。会話ポートレートは非表示、ノートは単列・縦スクロール、所持品は一列を維持する。

## 実装上の保護対象

- `AreaDefinition.obstacles`、exit bounds、hotspot position/radiusは変更しない。
- ゲーム状態、会話ID、item/owner/memory/ending ID、`saveVersion: 1`は変更しない。
- 描画は既存状態から `stage` と `reducedMotion` を導出する。
- PhaserのGraphics、Container、Tween、TimerはScene shutdownで破棄する。
- DOMのaria、フォーカス、Escape、タッチ入力ゲートを維持する。
