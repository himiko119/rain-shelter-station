# AreaArtLayout 設計

Art Integration V4 では、物語・進行を定義する `areas.ts` と、背景画像上の空間を定義する `areaArtLayouts.ts` を分離した。論理ワールドは従来どおり 1120×630 であり、既存の安定 ID と `saveVersion: 1` を維持する。

## 責務

`AreaArtLayout` は、各背景画像について次を一つの座標系で定義する。

- 歩行可能ポリゴン
- 家具・壁・線路などの障害物ポリゴン
- 出口のトリガーポリゴン、接近点、移動先の安全スポーン
- ホットスポットの絵上アンカーと床上の接近点
- Y 座標に応じた人物スケール
- 実在光源の影響領域と床反射
- 窓・屋外だけに限定した雨領域
- 床の反射・波紋領域
- 前景オクルーダーと基準 Y
- カメラ安全範囲

進行条件、会話、所有者、アイテム、ヒント、エンディング条件は従来のコンテンツ定義を正本とする。レンダリング定義が物語状態を変更することはない。

## 移動と補正

`isSafePoint` は、点が歩行可能ポリゴン内かつ膨張済み障害物外かを判定する。通常の主人公判定は約 14px のクリアランスを持つ。

`projectToSafePoint` は次の順で決定的に補正する。

1. 現在点が安全ならそのまま返す。
2. 安全スポーン、出口接近点、ホットスポット接近点を候補にする。
3. 8px グリッドを走査し、元位置から最短の安全点を選ぶ。
4. 同距離では Y、X の順で安定して選ぶ。
5. 指定クリアランスで安全点が存在しない場合のみ、クリアランス 0 で再試行する。

クリック移動では表示アンカーを目的地にしない。`artAnchor` はヒット領域・アイテム・人物の位置、`approachPoint` はナギが立つ床上位置として使う。家具を横断しない軽量グリッド経路を作り、各区間でも安全性を再検査する。

## 既存セーブ互換

保存中の `playerPosition` は「足元の論理ワールド座標」として解釈する。読み込み後、物語状態を変更せず現在エリアの `projectToSafePoint` を一度適用する。

- `saveVersion: 1` を維持する。
- 所持品、返却済みアイテム、手がかり、記憶、ヒント、エンディング記録は変更しない。
- 旧家具内、壁上、線路上、NaN/Infinity 相当の無効位置は安全スポーンへ復旧する。
- 補正済み位置は通常の自動セーブで保存され、再読み込み後も移動し続けない。

## 光・雨・反射

静的背景が利用できる場合、旧プロシージャル用の `activeLampPositions`、`rainRegions`、`rippleBands`、浮遊ラベルを利用しない。光源、雨、波紋は現在エリアのレイアウトだけから生成する。

`lightInfluenceAt` は複数の楕円領域を距離減衰で合成し、色、明るさ、影の不透明度、リムライト、反射色を返す。ホームの列車灯と夜明け光にはステージ条件を持たせる。

雨ポリゴンは屋内では窓・扉ガラス、屋外ではホーム・跨線橋の外部領域に限定する。波紋は指定された床上楕円へ限定し、駅員室には生成しない。

## 検証

単体テストでは、5エリアすべてについて以下を検査する。

- ポリゴンの有限値、面積、ワールド境界
- 安全スポーン、全出口接近点、全ホットスポット接近点
- 12px グリッドでの全接近点到達性
- 不正な旧セーブ位置の決定的補正
- 奥から手前への単調なスケール変化
- light zone の距離減衰とステージ条件

実ブラウザでは、キーボード・Canvas クリックの双方で足元サンプルを取り、床外侵入、家具横断、線路侵入、出口・ホットスポット到達性を確認する。
